# Dungeon Roguelike（地牢猎手：枪火重生）

使用Unity2022.3.43f1c1进行开发的 2D Roguelike 地牢冒险闯关游戏

## 项目状态

开发中。

## 使用技术

- Unity
- C#
- Universal Render Pipeline（URP）
- TextMesh Pro

## 当前内容

- 基础工程配置
- 渲染管线配置
- 部分美术资源与动画资源
- Tilemap 场景资源
- 字体与 UI 基础资源

## 后续计划

- 玩家控制系统
- 敌人 AI
- 武器与战斗系统
- 技能与升级系统
- UI 与背包系统
- 数据驱动与项目优化
